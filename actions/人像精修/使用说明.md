# 人像精修动作移植到 PhotoCraft — 使用说明

来源：`E:\qclaw\ps插件\人像精修.atn`（Photoshop 动作集「人像精修」，GBK 编码）
目标：PhotoCraft（`D:\Program Files\PhotoCraft`，photocraft-cli 0.20.2）

## 结论：可移植，已完成（并已修复播放中断）

### 中断问题的根因（重要）
原 `.atn` 共 42 步，其中 **4 步在 PhotoCraft 里不可用**：

| 原步骤 | 内容 | PhotoCraft 情况 | 处理 |
|---|---|---|---|
| 0 | 「如果」conditional | 无等价实现，**直接报错中断** | 删除 |
| 14 | `view.actualPixels`（PS「按屏幕显示比例」） | **命令根本不存在**，`actions.play` 遇未知命令直接报错中断 | 删除 |
| 39 / 40 | 「选择」select（画笔/选区事件） | 保留为 `photoshopStep`，播放必失败 | 删除 |

关键点：`view.actualPixels` 是纯界面缩放命令（PS 里把视图调到 100%），**对像素结果零影响**，删掉最干净。

之前只用 `actions.toggle` 把这 3 步"关掉"，**批处理路径能容忍（只警告），但 GUI 播放路径不容忍**——所以出现"批处理正常、GUI 一播放就中断"的现象。现已改为**物理删除这 4 步**。

修复后：`actions.play` 返回 `ran: 37`，无任何错误。

### 步骤映射（前 14 步，节选）
```
layer.new.layerViaCopy  →  复制当前层
layer.stampVisible       →  盖印可见图层
filter.blur.gaussianBlur(radius 2.3 / 4.4)
image.applyImage(blending=subtract, offset=128, scale=2)   ← 差值高反差
layer.setProps(blend="Linear Light")                        ← 线性光混合
layer.smartObjects.convertToSmartObject                    ← 转智能对象
layer.groupLayers / layer.layerMask.hideAll / tools.defaultColors
```
全部 38 步命令均能在 PhotoCraft 的 965 条命令注册表中一一对应。

## 用法

### GUI（PhotoCraft 窗口）
1. 打开 PhotoCraft → Actions（动作）面板 → 菜单 **Load Actions…**
2. 选 `人像精修-PhotoCraft.atn`
3. 打开照片 → 双击动作「完美磨皮@无忌视觉」

### 命令行批处理
```bat
"D:\Program Files\PhotoCraft\photocraft-cli.exe" batch ^
  --actions "E:\qclaw\projects\人像精修移植\人像精修-actions.json" ^
  --action "完美磨皮@无忌视觉" ^
  --in "<图片目录>" --out "<输出目录>" --format psd
```
```bat
"D:\Program Files\PhotoCraft\photocraft-cli.exe" droplet ^
  "E:\qclaw\projects\人像精修移植\人像精修-批处理.pcdroplet" "<图片目录>" --out "<输出目录>"
```

## 语义差异（务必知悉）

1. **3 个「停止」提示是原设计要求人工介入的**，PhotoCraft 会原样弹出：
   - 将你需要保留的细节部分模糊掉（高斯模糊 2.3px 那层）
   - 将中等瑕疵全部模糊掉（高斯模糊 4.4px 智能对象层）
   - 用 15% 流量白色画笔在黑色蒙版上涂抹修复皮肤

   GUI 里必须手动完成；命令行批处理会自动 `allowContinue` 跳过，所以**批处理输出是"未精修完成的中间态"**。
2. 被删的 `view.actualPixels` 只是视图缩放，无像素影响。
3. 被删的两个「选择」是 PS 的画笔/选区事件，无像素影响。
4. 输出 PSD 时图层结构完整保留：组「去瑕疵」内含「保留纹理」(Linear Light)、「去除中等瑕疵」(Smart Object + 高斯模糊 4.4)、「去除要保留的纹理」(隐藏)，顶层「使用修复画笔去除大的瑕疵」带黑蒙版。
